# Stitch Kitchen font assets

These files are self-hosted copies of the exact Google Fonts families declared by the authoritative Stitch Kitchen HTML:

- `bricolage-grotesque-latin.woff2` — Bricolage Grotesque, Latin, weight 500.
- `plus-jakarta-sans-latin.woff2` — Plus Jakarta Sans, Latin variable data used for weights 700–800.
- `work-sans-latin.woff2` — Work Sans, Latin variable data used for weights 400–600.
- `material-symbols-outlined.woff2` — Material Symbols Outlined, officially subset to `arrow_back`, `arrow_forward`, `chevron_right`, `favorite`, `home`, `inventory_2`, `menu_book`, `restaurant_menu`, and `star`, with weight and fill axes.

The source CSS and remote asset URLs are retained in `docs/stitch/reference/KITCHEN_SOURCE.html`. Local hosting prevents visual snapshots from changing with font-network availability.

The three text fonts are licensed under the SIL Open Font License 1.1; their upstream licence texts are stored beside the files. Material Symbols are licensed under Apache License 2.0; its upstream licence text is also stored here.
