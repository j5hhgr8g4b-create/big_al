## Source-of-truth model

Notion holds durable founder, business, product and brand truth. GitHub holds delivery truth for code, migrations, tests, CI, milestone execution and technical handover.

The wiki should explain what Big Al is and how it should behave. Live delivery status should stay in GitHub issues, `docs/CURRENT_STATUS.md` and `docs/HANDOVER.md` so the wiki does not become stale.
