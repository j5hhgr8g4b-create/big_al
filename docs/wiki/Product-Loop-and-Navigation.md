# Product Loop & Navigation

## Core loop

**Import → Save → Plan → Shop → Cook**

Big Al connects recipe collection to actual cooking. The product value is the workflow around the Cookbook.

## Primary navigation

- **Kitchen** — what matters now and the next useful action.
- **Cookbook** — saved recipes, Recipe Books, search and attribution.
- **Specials** — recipe discovery built around cooking behaviour.
- **Menu** — weekly meal planning.
- **Pantry** — shopping support, not full inventory management.

Cook Mode is the cooking companion: clear ingredients, readable steps and low distraction.

## Success

A Restaurant should be able to add or import a recipe, save it, plan it, generate useful shopping support, cook it successfully and decide whether it is worth cooking again.
