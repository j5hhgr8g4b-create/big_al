# User Journeys

## Journey model

Full product journey:

**Discover → Save → Organise → Plan → Shop → Cook → Improve → Return**

Protected current loop:

**Import → Save → Plan → Shop → Cook**

## Core journeys

1. Create or join a Restaurant and reach Kitchen with a clear next action.
2. Save a recipe into Cookbook so it can be found and used later.
3. Import a recipe from a URL while preserving source and creator attribution.
4. Browse, search and organise Cookbook without unnecessary admin.
5. Plan saved recipes in Menu.
6. Turn planned meals into practical shopping support in Pantry.
7. Cook from Big Al using clear ingredients and steps.
8. Save Restaurant cooking preferences so future guidance can become more useful.

## Quality rule

Every journey should reduce the effort between finding a recipe and cooking it. If a journey creates more admin than value, it needs simplifying.
