# Design Baseline

Big Al should feel like a trusted cookbook that quietly got smarter.

## Direction

Warm kitchen notebook + hand-drawn cookbook + cosy mobile app, with disciplined, readable UI.

## Principles

- food is the hero
- mobile-first
- warm, practical and friendly
- simple before decorative
- readable ingredients and cooking steps
- one clear primary action where possible
- Cook Mode should minimise distraction

## Primary navigation

Kitchen, Cookbook, Specials, Menu, Pantry.

## Visual baseline

- cream and warm-paper surfaces
- aubergine selected states
- herb green supporting colour
- tomato-red accent
- clean UI type for reading and controls
- handwritten accents only for short personality moments
- app frame around 430px on desktop, full width on mobile

For exact implementation tokens and icon SVGs, use `docs/design/` in the repository. Notion remains the product/design baseline summary.
